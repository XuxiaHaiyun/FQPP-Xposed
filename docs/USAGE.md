# 使用说明

## 打开控制面板

有两种方式进入配置界面：

1. **FQ++ 模块 App（主入口）**：直接打开 FQ++ 应用，首页展示激活状态卡片（框架连接状态、作用域授权），点击进入 **配置页** 修改各项开关；
2. **番茄小说内入口**：进入番茄小说 → 我的 → 设置，点击**标题栏右上角的 FQ++ 按钮**，弹出配置弹窗（只读展示当前配置，支持深色模式、Android 12+ 背景模糊），可一键跳转到模块 App 配置页。

## 配置存储机制

配置保存在 **FQ++ 模块 App 自身的 SharedPreferences** 中，番茄进程通过 libxposed API 102 的 `getRemotePreferences()` 跨进程只读读取，模块不会向番茄小说写入任何配置。

> ⚠️ 修改配置后需点击「保存配置」，**强制停止并重启番茄小说** 后全部功能才会加载生效。

## 启动 HTTP API 服务

HTTP 服务 **默认不随应用启动**。有两种启动方式：

- **方式一（推荐）**：在配置页开启「随番茄小说启动」，下次启动番茄小说即自动拉起服务；
- **方式二**：点击配置页的「导入书源」按钮（见下文，需番茄小说已启动且服务在运行）。

启动后可在同 WiFi 下用浏览器访问 `http://设备IP:9999/status` 测试是否正常（返回 `ok!`）。

## 导入书源到开源阅读

1. 确保番茄小说已启动且 HTTP 服务已运行（导入链接指向 `http://localhost:<端口>/booksource`，服务未运行时导入会失败）；
2. 在配置页点击 **「导入书源」** 按钮；
3. 模块会通过 `legado://booksource/importonline?src=...` 唤起开源阅读 App 完成导入；
4. 若未找到可处理该链接的应用（如阅读 App），会弹出提示；
5. 导入成功后，在阅读 App 书源列表中选择 **🍅 FQ Helper Simple** 书源即可搜索、阅读（探索页即书架）。

> 也可手动导入：在阅读 App 书源管理 → 网络导入，输入 `http://设备IP:9999/booksource`（端口按实际配置修改）。

导入后，局域网内任意设备（手机、平板、电脑、电子书阅读器）均可通过阅读器访问番茄小说资源。

## 功能开关

在配置页中按需开启以下开关（修改后点击「保存配置」）：

| 开关 | 默认 | 说明 |
|------|------|------|
| 端口号 | 9999 | HTTP 服务监听端口（0-65535） |
| 随番茄小说启动 | 关 | 番茄小说启动时自动拉起 HTTP 服务 |
| 阻止更新 | 关 | Hook `UpdateServiceImpl.checkUpdate` 全部重载，屏蔽番茄小说应用升级 |
| 本地会员 | 关 | 模拟 VIP 身份与去广告（需登录）：拦截用户信息（`AcctManager`）+ 会员特权（`PrivilegeManager`）+ 强制展示 VIP 卡片 |
| 界面净化 | 关 | 一键隐藏骚扰板块，见下方细分项 |
| 解封书籍 | 关 | Hook `BookUtils.isUnsafeBook` / `isOverallOffShelf`，解除部分下架/封禁书籍限制，**不保证 100% 解封**，视服务端校验策略而定 |
| 激励秒领 | 关 | Hook 激励视频页创建后立即关闭（等价"看完自动关闭"），SDK 正常发奖上报，广告一闪即过、奖励真实到账 |
| 禁用热更新 | 关 | 三层阻断 Reparo 热修复框架：不初始化、不拉取远程补丁、框架级 `enable()` 强制 false |
| 禁用插件加载 | 关 | 三层阻断 Mira 插件化框架：不初始化插件环境、不启动 Mira SDK、不下载远程插件。**慎用，可能导致崩溃** |
| 禁用崩溃上报 | 关 | 阻断字节 `NpthCore` 崩溃监控初始化 + `CrashReportConfig` 强制上报配置 `enable=false` |
| 阅读时长 5x | 关 | Hook `ReadingTiming.g()`，上报前将时长增量 ×5，快速刷满每日时长奖励 |
| 调试模式 | 关 | ImGui 悬浮日志层（支持暂停、关键词过滤、日志分级 DEBUG/INFO/WARN/ERROR）+ HTTP 响应以格式化 JSON 返回 |

## 界面净化细分项

需先开启「界面净化」总开关，细分卡片才会在配置页显示（关闭时整卡隐藏）。细分项默认值分两档：

**默认开启**（按需单独关闭）：

| 细分项 | 说明 |
|--------|------|
| 搜索框轮播提示 | 隐藏主页搜索框内轮播词 |
| 全屏福利广告弹窗 | 隐藏全屏广告弹窗 |
| 功能区 / 滑栏红点角标 | 隐藏功能区与右侧滑栏红点 |
| 侧滑「常玩游戏」 | 隐藏侧栏游戏入口 |
| 底部 TAB 角标 | 隐藏底部导航红点/文字角标 |
| 我的页小说推荐 | 隐藏「我的」页底部推荐 feed |
| 主页「赚钱」导航栏 | 隐藏底部「赚钱」TAB |
| 主页「短剧」导航栏 | 隐藏底部「短剧」TAB |
| 发表帖子 / 话题 / 书单按钮 | 隐藏书城/我的页的发布入口 |
| 我的页金币信息 | 隐藏金币/现金余额、提现板块 |
| 搜索页热搜榜 / AI 板块 | 隐藏搜索页热搜榜与 AI 内容 |
| 搜索页 AI 入口 | 隐藏搜索页 AI 横幅/悬浮按钮/搜索框入口 |

**默认关闭**（需主动开启才生效）：

| 细分项 | 说明 |
|--------|------|
| 我的页会员特权卡 | 开启本地会员时会默认展示 VIP 卡片，需主动开启该项才隐藏 |
| 我的页浏览历史外显 | ⚠️ **暂勿开启**：存在已知问题，影响正常使用 |
| 主页「点击赚钱」挂件 | 隐藏悬浮金币挂件（Lottie 动画） |

## 使用小提示

- 进入配置页按需开启各项开关，调整界面净化细分选项；
- 修改配置完成后记得保存，**强制停止重启番茄小说** 功能才会加载生效；
- 接口转发功能，局域网其他设备访问本机 IP:9999 即可对接；
- 如果模块失效，检查是否 App 自动更新，建议打开「阻止更新」开关。

> 接口列表与请求示例见 [API 接口](API.md)。
